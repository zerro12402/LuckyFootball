# Editable source inventory

Store editable art sources and lossless original audio here, grouped by type:

- `art/` for Aseprite, PSD, SVG, and other editable artwork.
- `audio/` for lossless original recordings and project files.

The current runtime asset set was supplied without editable originals. Its
provenance and release restrictions are recorded in
`res://docs/third_party_assets.md`. Do not treat exported PNG, MP3, or WAV files
as substitutes for missing editable sources.
