# Spec Delta

## Purpose

为单球员踢球闭环提供可复现的平面移动、转向和停止行为，将键盘或测试预设提交的方向意图转换为固定时间步长下的逻辑位移，使移动可以脱离场景显示独立测试。

## ADDED Requirements

### Requirement: 固定步方向移动
系统 SHALL 根据已登记的基础移速、移动意图和固定步长更新米制位置。输入向量长度 MUST 不超过 1；非有限方向和未知球员命令 MUST 被拒绝。

#### Scenario: 全速直线移动
- **WHEN** 无球球员基础移速为 4 m/s，提交向右移动并推进 0.25 秒
- **THEN** 球员沿 X 正方向移动 1 米

#### Scenario: 斜向移动限速
- **WHEN** 提交方向 (1, 1) 并推进固定步
- **THEN** 方向长度限制为 1，位移长度不超过相同步长的全速直线位移

#### Scenario: 未知球员移动
- **WHEN** 对未登记球员提交移动命令
- **THEN** 命令被拒绝，已登记球员的位置和状态不改变

### Requirement: 移动意图持续与显式停止
系统 SHALL 保持最近有效移动意图，直到新的移动或停止命令覆盖。零方向输入 MUST 停止基础移动并进入待机；停止不得清除最近左右朝向。

#### Scenario: 没有新输入
- **WHEN** 球员已收到移动命令，下一固定步未收到替代方向
- **THEN** 球员继续按原移动意图位移

#### Scenario: 停止
- **WHEN** 移动中的球员收到零方向命令
- **THEN** 后续基础位移为零且移动状态为待机

### Requirement: 左右朝向与移动方向分离
系统 SHALL 根据有效输入的 X 分量更新左右朝向。纯上、下移动与停止 MUST 保留上次左右朝向；显示不得反向修改逻辑朝向。

#### Scenario: 左转后向上移动
- **WHEN** 球员先向左移动，再收到纯向上的移动意图
- **THEN** 球员沿 Y 负方向移动且继续面向左侧

### Requirement: 帧率独立推进
系统 SHALL 以固定步累计和消费移动命令，按稳定球员 ID 顺序推进，向外提供状态快照。同一初始状态、配置、种子和固定步命令序列 MUST 得到相同移动结果。

#### Scenario: 显示帧不足一个固定步
- **WHEN** 累计显示时间尚未达到固定步长
- **THEN** 比赛位置不提前更新，待累计时间足够后才推进

#### Scenario: 重放移动
- **WHEN** 两次模拟使用相同初始状态与固定步移动命令
- **THEN** 对应时刻的球员位置和移动状态一致
