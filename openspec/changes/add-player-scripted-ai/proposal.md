# Proposal

## Why

在已实现的一名前锋脚本试跑基础上，让玩家为选定球队提交一份脚本，供前锋、中场、后卫和门将使用。脚本按当前球员的位置和局面选择行为。

## What Changes

- 复用 v1 已实现的本地脚本编辑、静态校验、绑定和固定种子试跑。
- 脚本提交时解析为内部表示，比赛决策时通过受限 API 执行；不转译为 GDScript。
- 支持调整合法行为权重或直接选择合法行为及目标；失败回退内置 AI 并显示原因。
- 发布与接口版本匹配的可下载 Markdown 手册，提供示例和给生成式 AI 的提示词。
- 本次扩展以球队为绑定单位，提交一次即可覆盖该队所有位置；各球员独立调用脚本。扩展位置条件、行为和目标，原单前锋 v1 试跑继续兼容。
- 门将留门约束保持。脚本不一次返回全队命令；赛后 Markdown／JSONL 导出、逐帧日志及联网投稿仍不在范围内。

## Capabilities

### New Capabilities

- `player-scripted-ai`：玩家脚本的提交、执行、单球员试跑和公开使用说明。

### Modified Capabilities

无。既有比赛规则、内置 AI 默认行为和比赛阶段权限继续适用。

## Impact

规划涉及球员决策策略、脚本运行与校验、只读公开接口及本地试跑入口。详见 [策划](https://app.notion.com/p/411f67bb9cfa81f8a5a8c2762441362f) 和 [程序设计](https://app.notion.com/p/411f67bb9cfa818684aec198faf6f760)。
