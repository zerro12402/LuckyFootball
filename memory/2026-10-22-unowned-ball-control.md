# 无主飞行球重新控球

- 状态：DONE。
- 症状：射门反弹返回射手后无法重新控球；统一检查发现传球只检查指定目标、解围无接球入口、射门刚停止时本步漏检球权。
- 根因：普通获取球权仅处理 LOOSE；SHOT 和 CLEARANCE 推进后直接返回，PASS 使用独立指定目标分支；MatchSimulation 按步初飞行状态决定是否允许步末捡球。原接球高度只检查球心，反弹球可能错过脚部可接触范围。
- 修复：BallShotTrajectory 统一预测减速射门与恒速传球/解围；BallRuntimeSystem 按连续球路与球员移动轨迹求首次合法控球接触，统一检查动作、无球状态、球速、地面/空中高度和释放保护，以唯一原子提交路径设置球权并清除旧射门来源。地面球心高度上限为 0.2 m 加配置球半径，空中仍使用 AIRBORNE 与 0.5 m 高度差。
- 调度：MatchSimulation 对射门同时比较控球、身体接触与完整球体越界时刻，身体/边界在完全同时优先；边界先发生则不接球；控制点越界仍走带球出界结算。刚停止的球同一步检查普通球权，未注册足球的纯移动模拟保留空值保护。
- 保护：传球、射门和头球释放统一登记最近释放者，仅限制本人；接球与重置清除保护。动作锁定、倒地、过高和过快的球不自动接住，进球/出界等待阶段不处理新球权。
- 回归测试：tests/unit/test_unowned_ball_control.gd。修复前实际复现返回射门、非目标接传球、低空解围和刚停止漏检四类失败；修复后通过。补充速度边界、过高球、所有动作锁、保护期、稳定 ID 决胜、唯一持有者、移动扫掠及先越界后接触测试。
- 旧测试调整：test_ball_impact_flow.gd 检查反弹事件的瞬时方向，而非假设最终仍无人持有；连续多次反弹的碰撞专项测试显式降低控球速度阈值，防止普通接球提前结束该碰撞用例。
- 验证：全部 35 个非表现类单元测试通过，同时检查进程退出码与脚本错误；git diff --check 通过。按项目要求未执行截图、录屏或渲染相关测试。
